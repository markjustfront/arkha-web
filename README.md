# arkha-web
Static promo site for ARKHA POS (arkha.eu). Plain HTML/CSS + a tiny i18n/theme script (ES/CA/EN). Self-hosted fonts (Jost, Michroma — SIL OFL 1.1), no cookies, no tracking, no third-party requests.
