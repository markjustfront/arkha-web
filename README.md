# arkha-web
Static promo site for ARKHA POS (https://arkha.eu). Plain HTML/CSS + a tiny i18n/theme script (ES/CA/EN). Self-hosted fonts (Jost, Michroma — SIL OFL 1.1), no cookies, no tracking, no third-party requests.

Contact: holaarkha@gmail.com. Owner details on the legal pages are placeholders (no personal tax data).

Preview locally: `python3 -m http.server` in this folder.
